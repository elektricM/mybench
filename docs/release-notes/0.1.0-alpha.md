# MYBENCH 0.1.0-alpha

First public pre-release of MYBENCH, a single-window replacement for NI ELVISmx for the NI myDAQ.
It needs no NI software: it talks to the myDAQ over USB through its own driver (`libmydaq`, C,
libusb). Without a myDAQ it runs on a built-in simulated device.

This is an alpha: everything below ran on a real myDAQ from macOS, but tests that need external
wiring, and real-device runs on Windows and Linux, are still to come (see "Verified on a real myDAQ").

## What works

Instruments (each with a help page and simulator tests; parity with ELVISmx tracked row by row in
`docs/audit.md`):

- Multimeter: DC/AC voltage and current, resistance, diode, continuity (with tone), trend, statistics, logging.
- Oscilloscope: ELVISmx-style acquisition and triggers, measurements, math, FFT, XY, persistence, references, roll mode.
- Waveform Generator: function generator, arbitrary waveforms, DC level, sweeps, Waveform Editor (`.wdt` export, `.wfm` open best effort).
- Bode Analyzer: standard and fast sweeps, markers, references.
- Spectrum Analyzer: harmonics, THD, SINAD, spectrogram, 1/3-octave mode.
- Digital I/O: reader, writer, logic timeline.
- Counter/Timer, Data Logger (ELVISmx-compatible text logs), Audio Equalizer.

Shell and platform:

- Single window: launcher/dashboard, tabs, favourites, session save/open (`.mybench`), help that follows focus, print dialog.
- Instrument safe state: outputs return to 0 V / inputs on panel close, reset and Stop.
- Driver: analogue in and out running concurrently, hardware-timed AI/AO, audio in/out, counters and frequency output, all DMM modes.
- Packages: macOS DMG (universal), Linux AppImage, `.deb`, `.rpm` (with the udev rule), Windows installer and zip.
- Automated tests (simulator, mock transport, capture replay) run on macOS, Linux (Qt 6.9 and 6.11) and Windows in CI.

Out of scope for this release: the 8-channel oscilloscope and the Digital Waveform Viewer as
separate apps (mapped to Scope and Digital I/O).

## Verified on a real myDAQ (macOS host, serial 036CD1C6, no external wiring)

- Hardware test suite (`MYDAQ_HW_TESTS=1 ctest -L hw`): 13/13 pass. All nine instruments run
  headless on the device.
- AI 2 x 200 kS/s together with streamed AO 2 x 200 kS/s: 0 underflows (5/5 on an idle machine,
  5/5 with 4 cores busy, 2/2 with all 10 cores busy). AO starts in 50-75 ms; first AI data ~130 ms.
- Multimeter: all modes answer (V, A, Ω 200 Ω-20 MΩ, diode, continuity); diode/continuity use the
  mode bytes captured from ELVISmx (a 150 Ω resistor read 149 Ω, a green LED 1.618 V); 2 readings/s
  (V/A/Ω), ~10/s (diode/continuity); autorange settles without hunting.
- Counter/Timer on the internal FREQOUT loop: frequency, period, pulse width, semi-period, two-edge
  separation, edge counting (incl. 20 MHz / 100 kHz sources, initial count), encoders, pulse trains
  (idle state, initial delay, live frequency/duty change); FREQOUT 6.25 kHz-20 MHz within 0.02 %.
- Digital I/O patterns read back exactly; audio in/out, Spectrum Analyzer, Data Logger and Audio
  Equalizer stream without dropouts.
- Not yet verified with wiring (needs jumpers or components): AO accuracy into AI (AO0 -> AI0),
  Bode sweeps, counter inputs on the DIO pins (DIO4 -> DIO1), resistance readings above 20 kΩ,
  DMM hardware autorange. Windows and Linux have not been run against a real myDAQ yet.

## Known issues

- Counter external direction (count up/down from a pin) and buffered counter input are not
  available (the myDAQ/DAQmx refuse them); the Counter/Timer panel greys them out.
- Two-edge separation on the DIO pins uses routes inferred from the driver; verified only on the
  internal loop.
- A DMM range change takes 2-3 s (the meter's own settling time).
- Open items in `docs/audit.md` (marked OPEN), e.g. a second math trace and FFT window choice in
  the Scope, Bode log-axis label style.
- `.wdt` loading is best effort: no real `.wdt` file was available to validate against.
- Windows: the WinUSB driver must be bound to the myDAQ (Zadig) before MYBENCH can use it; NI's
  software then no longer sees the device. The installer does not bundle the driver tool.
- macOS: builds are signed ad hoc, so Gatekeeper blocks the first launch (see install below).
- Linux: the AppImage cannot install the udev rule; do it by hand.
- Only the myDAQ with NI's firmware (USB `3923:755b`) is supported. MYBENCH never writes device flash.

## Install

Full instructions: `docs/INSTALL.md`.

**macOS (14 or later, Apple Silicon and Intel)**
1. Open `MYBENCH-0.1.0-macOS-universal.dmg`, drag MYBENCH to Applications.
2. First launch: Control-click, Open, Open; or `xattr -dr com.apple.quarantine /Applications/MYBENCH.app`.
3. Plug in the myDAQ. No driver needed.

**Linux**
- Fedora 42+ (Qt 6.9+): `sudo dnf install ./mybench-0.1.0-1.x86_64.rpm`. No `plugdev` group is
  needed; the udev rule uses `uaccess` for the logged-in desktop user. Re-plug the myDAQ.
- Debian 14 / Ubuntu 25.10+: `sudo apt install ./mybench_0.1.0_amd64.deb`, re-plug the myDAQ.
- Any distribution (glibc 2.35+): `chmod +x MYBENCH-0.1.0-linux-x86_64.AppImage && ./MYBENCH-0.1.0-linux-x86_64.AppImage`,
  and install `60-mybench-mydaq.rules` into `/etc/udev/rules.d/` by hand, then
  `sudo udevadm control --reload-rules && sudo udevadm trigger` and re-plug.
- Wayland and X11 are both supported by Qt; on Fedora install `qt6-qtwayland` if it is missing
  (KDE Plasma normally has it).

**Windows 10/11 (x64)**
1. Run `MYBENCH-0.1.0-windows-x64.exe` (or unpack the zip).
2. Bind WinUSB to the myDAQ with Zadig (Options, List All Devices, NI myDAQ, WinUSB, Replace Driver), re-plug.

Check the install with `mybench --version` and `mybench --simulated`.
