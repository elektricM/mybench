MYBENCH is an open-source replacement for NI ELVISmx for the NI myDAQ: multimeter, oscilloscope,
waveform generator, Bode and spectrum analyzers, digital I/O, counter/timer, data logger and audio
equalizer in one window. It talks to the myDAQ directly over USB (no NI software needed), and has a
built-in simulated myDAQ so you can try everything without hardware.

This is the first public beta. Please report what breaks, especially on Windows and Linux with a
real myDAQ, which have had much less testing than macOS.

## What's new since 0.1.0-alpha.2

- **New interface.** One sidebar with the live state of every instrument, side-by-side split by
  drag and drop, instrument panels with direct controls (knobs, typed values, scroll to change),
  native look on macOS, Windows and KDE, light and dark themes.
- Waveform Editor rebuilt; Bode and Audio Equalizer moved to the new panel layout.
- "Reset to defaults" per instrument.
- The myDAQ's analog inputs also work in PulseView / sigrok-cli and ngscopeclient
  (see `docs/integrations.md`; needs a build from source).
- Flatpak bundle for Linux.

## First start

- **macOS:** the app is not notarized. On first launch macOS refuses to open it: go to
  System Settings → Privacy & Security → **Open Anyway**, or run
  `xattr -dr com.apple.quarantine /Applications/MYBENCH.app`.
- **Windows:** SmartScreen may warn about an unknown publisher (More info → Run anyway). To use a
  real myDAQ, the WinUSB driver has to replace NI's driver for the device (one-time, with
  Zadig). `docs/INSTALL.md` has the steps, and how to switch back to NI's driver.
- **Linux:** the `.deb` and `.rpm` install the udev rule. With the Flatpak or AppImage, install
  `60-mybench-mydaq.rules` once by hand (see `docs/INSTALL.md`), otherwise only root can open the
  myDAQ.
- The myDAQ needs NI's firmware, which it has if it was ever used with NI ELVISmx or NI-DAQmx.

## Known limitations

- Verified on a real myDAQ from macOS only. Hardware-timed analog output, DMM current/resistance,
  diode/continuity and the counter inputs still need checks with wiring.
- The 8-channel oscilloscope and the Digital Waveform Viewer from ELVISmx are not separate apps
  (their functions are in the Oscilloscope and Digital I/O).
