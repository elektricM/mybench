**Open-source instrument software for the NI myDAQ.** Multimeter, oscilloscope, waveform generator,
Bode and spectrum analyzers, digital I/O, counter/timer, data logger and audio equalizer in one
window. It talks to the myDAQ directly over USB, so no NI software is needed. A simulated myDAQ is
built in, so you can try everything without hardware.

This is the **first public beta**. Please [report what breaks](https://github.com/elektricM/mybench/issues),
especially on Windows and Linux with a real myDAQ.

## 🚀 First start

> [!IMPORTANT]
> **macOS:** the app isn't notarized yet. On first launch go to **System Settings → Privacy & Security → Open Anyway**
> (or run `xattr -dr com.apple.quarantine /Applications/MYBENCH.app`).
>
> **Windows:** SmartScreen may warn about an unknown publisher (*More info → Run anyway*). To use a real
> myDAQ, switch it to the WinUSB driver once with [Zadig](https://zadig.akeo.ie).
>
> **Linux:** the `.deb` and `.rpm` set up USB access for you. With the Flatpak or AppImage, install the
> udev rule once.
>
> Step-by-step for every OS: [docs/INSTALL.md](https://github.com/elektricM/mybench/blob/main/docs/INSTALL.md)

The myDAQ needs NI's firmware, which it already has if it was ever used with NI ELVISmx or NI-DAQmx.

## ✨ What's new since 0.1.0-alpha.2

- **New interface.** A sidebar shows the live state of every instrument. You can drag panes into
  a side-by-side split, use direct controls (knobs, typed values, scroll to change), get a native
  look on macOS, Windows and KDE, and pick light or dark theme.
- Waveform Editor rebuilt; Bode and Audio Equalizer moved to the new panel layout.
- **Reset to defaults** per instrument.
- The myDAQ's analog inputs also work in **PulseView / sigrok-cli** and **ngscopeclient**
  ([docs/integrations.md](https://github.com/elektricM/mybench/blob/main/docs/integrations.md), build from source).
- New **Flatpak** package for Linux.
- **Open source:** GPL-3.0-or-later for the app, LGPL-2.1-or-later for the `libmydaq` driver library.

## ⚠️ Known limitations

- Tested on a real myDAQ from macOS only. Hardware-timed analog output, DMM current/resistance,
  diode/continuity and the counter inputs still need checks with wiring.
- The 8-channel oscilloscope and the Digital Waveform Viewer from ELVISmx are not separate apps;
  their functions are in the Oscilloscope and Digital I/O.
